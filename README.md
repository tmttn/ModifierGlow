# Modifier Glow

While you hold **Shift**, **Ctrl** or **Alt**, Modifier Glow lights up the action buttons you can use with that modifier:

- buttons bound to a key with that modifier (SHIFT-1, CTRL-Q, CTRL-SHIFT-E)
- macros whose conditions ask for it (`[mod]`, `[mod:shift]`, `[nomod]`)

The other buttons can be dimmed so the ones that matter stand out.

## Features

- A colour, glow strength and animation for each of Shift, Ctrl, Alt and "two or more"
- 12 glow styles (ants, clean line, classic alert, classic gold; circling, breathing or still), the same look as Glowing Bars
- Glow always, only in combat, only out of combat, or only with an enemy / ally / anyone targeted
- Works with Blizzard's bars, Bartender4 and Dominos

## Commands

`/modglow` opens the options.
